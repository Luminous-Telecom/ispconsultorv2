# Logos das Marcas

Esta pasta contém as logos das marcas exibidas na seção "Marcas e Tecnologias" do site.

## Como adicionar logos:

1. Baixe as logos das marcas em formato PNG ou SVG
2. Renomeie os arquivos conforme a lista abaixo (em minúsculas)
3. Coloque os arquivos nesta pasta (`/public/logos/`)

## Nomes dos arquivos esperados:

### OLT
- `vsol.png` ou `vsol.svg`
- `fiberhome.png` ou `fiberhome.svg`
- `overteck.png` ou `overteck.svg`

### Roteador de Borda
- `huawei.png` ou `huawei.svg`
- `mikrotik.png` ou `mikrotik.svg`

### Switch
- `intelbras.png` ou `intelbras.svg`

### ERPs

- `sgp.png` ou `sgp.svg`

### Monitoramento

- `anatel.png` ou `anatel.svg`

## Recomendações:

- Use formato PNG com fundo transparente ou SVG
- Tamanho recomendado: largura máxima de 120px
- Altura recomendada: 20-40px
- Mantenha proporção original da logo
- Use logos em alta qualidade (mas otimizadas para web)

## Nota:

Se uma logo não for encontrada, apenas o texto da marca será exibido. O sistema trata erros de carregamento automaticamente.
