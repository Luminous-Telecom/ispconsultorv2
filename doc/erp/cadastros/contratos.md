# Contratos

Visão **global** de todos os contratos da empresa — útil para consultar ou editar contratos sem abrir o cadastro de cada cliente.

::: tip Forma recomendada
Para **criar** um contrato novo, prefira **Cadastros → Clientes → aba Contratos** — o cliente já vem vinculado. Veja o guia completo em [Aba Contratos](/doc/clientes/aba-contratos).
:::

## Como acessar

1. Faça login no painel administrativo.
2. No menu lateral, abra **Cadastros**.
3. Clique em **Contratos**.

## Listagem

A tela segue o padrão de [listagens do ERP](/doc/geral/listagens). Abaixo, apenas o que é **específico** desta tela.

### Barra de ações

| Botão | Função |
|-------|--------|
| **Novo** | Abre o formulário de novo contrato |
| **Editar** | Edita o contrato selecionado |
| **Deletar** | Remove o contrato selecionado |
| **Imprimir** | Gera impressão do contrato selecionado |

### Busca — campos disponíveis

- ID
- Cliente (razão social do cliente)
- Plano
- Status
- Valor Final
- Endereço
- Cidade
- Estado

---

## Criar um contrato por este menu

1. Clique em **Novo**.
2. Selecione o **cliente** e preencha os demais campos — o fluxo é o mesmo descrito em [Aba Contratos → Criar um contrato](/doc/clientes/aba-contratos#criar-um-contrato--passo-a-passo).
3. Clique em **Salvar**.

Após salvar, as abas **Termos**, **Financeiro**, **Financeiro Avulso**, **Serviços Adicionais** e **IXC Provedor** ficam habilitadas. Detalhes de cada aba estão em [Aba Contratos](/doc/clientes/aba-contratos#abas-após-salvar).

---

## Pré-requisitos

Antes de criar contratos, configure os cadastros listados em [Antes de criar um contrato](/doc/clientes/aba-contratos#antes-de-criar-um-contrato).
