# Aba Arquivos

Orientações para consultores sobre o **armazenamento e consulta de documentos** vinculados a um cliente.

## Como acessar

1. Abra **Cadastros → Clientes**.
2. Edite o cliente desejado.
3. Clique na aba **Arquivos**.

A aba só fica disponível **após salvar** o cadastro do cliente.

---

## Listagem

A tela segue o padrão de [listagens do ERP](/doc/geral/listagens). Abaixo, apenas o que é **específico** desta aba.

### Barra de ações

| Botão | Função |
|-------|--------|
| **Novo** | Abre o seletor de arquivo para upload |
| **Deletar** | Remove o arquivo selecionado |
| **Visualizar** | Abre o arquivo selecionado para visualização |
| **Baixar** | Faz download do arquivo selecionado |

::: tip Seleção de registro
**Deletar**, **Visualizar** e **Baixar** ficam desabilitados até que um arquivo seja selecionado na tabela.
:::

### Enviar um arquivo

1. Clique em **Novo**.
2. Selecione o arquivo no seletor do sistema operacional.
3. O upload é concluído automaticamente após a seleção — não há formulário adicional.

### Busca — campos disponíveis

- ID
- Nome
- Tipo de Arquivo
- Origem do Arquivo

---

## Boas práticas

- Use nomes de arquivo descritivos antes do upload — facilita a busca posterior.
- Prefira formatos comuns (PDF, PNG, JPG) para garantir visualização no navegador.
- Evite excluir documentos com valor legal ou histórico de atendimento; consulte a equipe quando houver dúvida.
