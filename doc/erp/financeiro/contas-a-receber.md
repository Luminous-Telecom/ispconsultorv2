# Contas A Receber

Visão **global** de todos os títulos a receber da empresa — de todos os clientes e contratos. Para operar títulos de um cliente específico, use também a [Aba Financeiro](/doc/clientes/aba-financeiro) no cadastro do cliente.

## Como acessar

1. Faça login no painel administrativo.
2. No menu lateral, abra **Financeiro**.
3. Clique em **Contas A Receber**.

::: tip Onde gerar títulos
Títulos recorrentes são criados em **Contratos → aba Financeiro → Gerar Financeiro**. Títulos avulsos, na aba **Financeiro Avulso** do contrato. Veja [Aba Contratos](/doc/clientes/aba-contratos).
:::

---

## Listagem

A tela segue o padrão de [listagens do ERP](/doc/geral/listagens). Abaixo, apenas o que é **específico** desta tela.

### Barra de ações

| Botão | Função |
|-------|--------|
| **Editar** | Abre o título selecionado para alteração |
| **Deletar** | Remove o título selecionado |
| **Receber** | Registra a baixa (pagamento) do título |
| **Cancelar** | Cancela o título selecionado |
| **Estornar** | Estorna um pagamento já registrado |
| **Imprimir** | Menu de impressão de boletos/recibos |
| **Enviar** | Envia a cobrança ao cliente via WhatsApp ou e-mail |
| **NFS-e** | Ações de nota fiscal de serviço eletrônica |

::: tip Seleção de registro
A maioria das ações fica desabilitada até que um título seja selecionado na tabela.
:::

### Filtro por período

- **Data Inicial** e **Data Final** — restringe a listagem ao intervalo informado

### Busca — campos disponíveis

- ID
- Número do Título
- Cliente
- Plano
- Contrato
- Status
- Valor
- Valor baixado
- ID da Cobrança
- Nosso Número

### Filtro

- **Mostrar cancelados** — exibe também títulos cancelados

## Diferença em relação à aba Financeiro do cliente

| Tela | Escopo |
|------|--------|
| **Financeiro → Contas A Receber** | Todos os títulos de todos os clientes |
| **Clientes → aba Financeiro** | Títulos de um cliente específico |

As ações disponíveis são as mesmas. Fluxos detalhados:

- [Editar um título](/doc/clientes/aba-financeiro#editar-um-titulo)
- [Receber um pagamento](/doc/clientes/aba-financeiro#receber-um-pagamento)
- [Cancelar um título](/doc/clientes/aba-financeiro#cancelar-um-titulo)
- [Enviar cobrança e NFS-e](/doc/clientes/aba-financeiro#enviar-cobranca-e-nfs-e)
