🔍 Debug - Edição de Contratos

❌ Problema Identificado:

Ao clicar em "Editar Contrato" aparece primeiro:

  • "Cliente atualizado com sucesso!"
  • Depois abre o modal de edição

Isso indica uma ação conflitante sendo executada!

🔍 Debug Implementado:

  1. Abra o frontend: http://localhost:3000
  2. Vá para Clientes → Editar cliente ID 1
  3. Vá para a aba "Contratos"
  4. Selecione um contrato e clique em "Editar"
  5. Abra o console do navegador (F12) e observe os logs

✅ Logs Esperados (em ordem):

  1. "🔍 Debug ClienteEditModal - Editar contrato clicado!"
  2. "🔍 Debug - selectedItems: [objeto do contrato]"
  3. "🔍 Debug - Abrindo modal de edição para contrato ID: 12"
  4. "🔍 Debug - Renderizando ContratoEditModal, show: true"
  5. "🔍 Debug ContratoEditModal - contratoData: [dados do contrato]"
  6. "🔍 Debug - Carregando dados do contrato: [dados]"

⚠️ Possíveis Causas do Problema:

  • useQuery conflitante: Pode estar executando uma query de cliente em vez de contrato
  • URL incorreta: API pode estar chamando endpoint errado
  • Hook conflitante: useUpdateContrato pode estar sendo executado prematuramente
  • Evento duplicado: Pode haver dois event handlers sendo executados
  • Cache invalidation: QueryClient pode estar invalidando queries incorretas

🔧 URLs das APIs:

  • Buscar contrato: GET {API_URL}/contratos/{id}
  • Atualizar contrato: PUT {API_URL}/contratos/{id}
  • Buscar cliente: GET {API_URL}/clientes/{id}
  • Atualizar cliente: PUT {API_URL}/clientes/{id}

📋 Teste Manual da API:

Teste se a API está funcionando corretamente:

  • Buscar contrato: curl -X GET "http://localhost:3001/api/contratos/12"
  • Atualizar contrato: curl -X PUT "http://localhost:3001/api/contratos/12" -d '{"observacoes":"teste"}'
